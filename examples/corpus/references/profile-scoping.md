# Profile scoping reference

The synthetic coding profile should prioritize `core/active.md`, `core/env.md`, and `core/defaults.md`.

It should avoid personal paths such as `people/**` and `knowledge/personal/**` when answering coding tasks.

Profile-scoped retrieval should explain when a source was filtered out by policy instead of silently ignoring the user's requested scope.
