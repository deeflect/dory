# Dory public principles

Dory treats markdown as the source of truth. SQLite indexes are disposable sidecars that can be rebuilt.

Public examples, evals, and docs must use synthetic facts only. Real biographies, finances, health details, direct contact details, private hostnames, tokens, and local machine paths do not belong in public fixtures.

Agent-facing answers should cite source paths when they depend on memory evidence.
